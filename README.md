# 🧠 Brain Simulation

Izhikevich (2003) neuron modeli ile gerçekçi beyin ağı simülasyonu.

## 📊 Özellikler

- **1000 sinir hücresi** (800 uyarıcı + 200 engelleyici)
- **Izhikevich modeli** – biyolojik olarak gerçekçi nöron dinamiği
- **Talamik gamma sürücüsü** – 40 Hz osilasyon
- **3D görselleştirme** – dönen küre içinde canlı ağ
- **Spike-timing dependent plasticity** (STDP) – öğrenme mekanizması
